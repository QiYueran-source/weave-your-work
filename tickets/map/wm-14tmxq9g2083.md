## Target

A project whose tree no longer describes its work can be restarted: what is still usable is written down first, then a new root map starts, and the old tree is archived with a pointer to that record.

Why: when a tree is a mess the instinct is to delete it and start clean, which throws away the part that was real — the work that actually finished, the vocabulary, the dead ends already ruled out. The new tree then rediscovers them at full price.

## Acceptance direction

All children are complete and no further children are needed.

Review point: `weave-your-work/salvage-and-restart/SKILL.md` names the trigger, the order of the five steps, where the salvage record lives and what it holds, how a subtree that survives is moved instead of archived, and what the skill never does. The task that writes it runs the order on a scratch waymark project and leaves one archived tree, one new root citing the record, and no ticket parenting to an archived node.
