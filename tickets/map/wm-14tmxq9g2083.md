## Target

A project whose tree no longer describes its work can be restarted: what is still usable is written down first, then a new root map starts, and the old tree is archived with a pointer to that record.

Why: when a tree is a mess the instinct is to delete it and start clean, which throws away the part that was real — the work that actually finished, the vocabulary, the dead ends already ruled out. The new tree then rediscovers them at full price.

## Acceptance direction

All children are complete and no further children are needed.

Review point: `weave-your-work/salvage-and-restart/SKILL.md` names the trigger, the order of the five steps, where the salvage record lives and what it holds, how a subtree that survives is moved instead of archived, and what the skill never does. The task that writes it runs the order on a scratch waymark project and leaves one archived tree, one new root citing the record, and no ticket parenting to an archived node.

## Decisions so far

- The old tree is archived, never deleted; the salvage record is written before the first archive command runs. (user confirmed, 2026-11-10)
- The salvage record lives at `docs/salvage/YYYY-MM-DD-<topic>.md`, and the new root map cites it from `Decisions so far`. (user confirmed, 2026-11-10)
- The skill is named `salvage-and-restart`: the name carries both halves, keeping what works and starting the new tree. (user confirmed, 2026-11-10)
- It hangs directly under the root map, not under a new category map. (user confirmed, 2026-11-10)
- Archive runs bottom-up, children before parents, each with an `archive_reason` naming the replacement and the record. A ticket archived before its parent would leave the old tree unreadable in `waymark tree`. (agent decision, from the update skill's retire order)
- The old root is archived too, so exactly one root is left standing. The archived root keeps the entry point for a reader of the failed attempt, and `waymark tree --root <old-root>` still shows that tree with each node's reason. (user confirmed, 2026-11-10)
