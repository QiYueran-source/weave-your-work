# Write in English

User-facing writing in this repository is in English: documentation, reports, summaries, commit messages, PR descriptions, changelog entries, comments, and any text a person will read.

## What to do

- Write in plain, accurate English that a reader understands on the first pass.
- Follow the `talk-like-a-human` skill for wording: no buzzwords, no vague hedges, no filler, one name for one thing, first line says the result.
- Do not translate technical terms that have a fixed meaning. Keep code names, commands, file paths, and error text as they are.
- When a term has no established English name, say what it is in one sentence on first use, and keep using the same name after that.
