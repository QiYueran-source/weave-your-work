# Reference copies

Copies of [`mattpocock/skills`](https://github.com/mattpocock/skills), kept as a reading reference for the skill stack this repository learned from.

Install them from the source, not from here:

```sh
npx skills add mattpocock/skills
```

The directory is named `.agents/matt-skills/` rather than `.agents/skills/` on purpose. `npx skills` treats `.agents/skills/` as a discovery container and an install target, so a copy sitting there would be listed alongside this repository's own skills and would shadow same-named ones. The rename keeps the reference readable without changing what an install of this repository returns.
