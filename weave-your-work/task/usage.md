# Task usage

Use `SKILL.md` as the entry point. It routes task design, execution, batch execution, and review to their owning skills.

- Read `task-design` references to write a task ticket.
- Use `execute-one-task` to advance one task, or `execute-all` to run the tasks under a map.
- Use `task-review` to judge a finished task.
- Use `split` to decide whether new work becomes a task or child map.
- Use `update` when changing a closed task or a map with children.

For installation of the task work-record rule, read `bundle/setup.md`.
