# Use weave-your-work examples

These are worked examples of the method in use. The building, update, and issue examples come from the project's own build; the chemistry scenario is fictional.

Read them when:

- you are about to write a map and want to see a complete one;
- you are unsure whether a function detail should be a child map or a task;
- you want to see a fog item arrive as a child;
- you are working a task and want to see the design, run, batch, and review paths together.

## Files

- `building-work-weave/README.md`: how this project split its own tree, in order.
- `chemistry-research/README.md`: a fictional lab scenario that walks the task skills, with a scratch waymark project and the findings from the walk.
- `designing-the-update-skill/README.md`: how one design map became the update skill, and the four decisions that were reversed on the way.
- `designing-the-issue-skill/README.md`: how the communication map became a skill for GitHub and Gitee, and why the decisions landed in the ticket rather than a second document.
- `map-example.md`: one complete map.
- `task-example.md`: one complete task.
