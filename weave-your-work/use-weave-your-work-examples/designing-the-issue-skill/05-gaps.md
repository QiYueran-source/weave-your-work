# What this example does not show

- **A Gitee write.** GitHub's five actions were run end to end on a private scratch repository on 2026-11-08; the probe issue is closed and the repository is archived. Gitee's create, comment, and close were deferred by the user on 2026-11-08: the reference stays, its reads and endpoints are checked, and the end-to-end batch will run the writes. The acceptance is judged on GitHub until then.
- **A blind read of the skill.** Four fresh readers, each given only the three files and the caller's design ticket, walked the archive, human-step, foreign-parent, and outside-proposal cases; all four could execute it. They found the boundary gaps the rules now answer: who names the recipient and what happens without a handle or account, who gives the public-repo yes when the repository is not the run's, where the receipt lives when no replacement exists or the continuing ticket is foreign, how a closed thread with the same id is found, the command for a status change, how a proposal with no ticket is found and judged, where its new ticket's source goes, how a decline closes, and the fact that nothing watches a thread. Four readers match the update skill's build; each read one case. A fifth re-read the proposal case after the triage and handle rules landed; it found three more boundary gaps — which map judges a proposal with no local ticket, what the closing comment names when there is no ticket, and who writes the `Out of scope` line when the judge is not the run's owner. The rules now answer each.
- **A real cross-owner hand-over.** Every ticket in this repository is owned by `frank`, so the archive example in [Three callers and one message](01-three-callers.md) is a scenario, not a run. The shape is checked against the update map's rule; the delivery is not.
- **The `comment` category's fate.** The skill does not use it, but the category is still declared and the glossary still defines it. Whether it stays is a decision for the execution map, which owns the question.
- **The end-to-end batch.** The root map runs every skill's paths once the set is whole. This example records the design of one skill; it is not that test, and it does not claim the issue skill works beside the others.
