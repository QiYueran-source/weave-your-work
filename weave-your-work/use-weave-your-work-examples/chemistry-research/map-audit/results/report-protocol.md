# Synthetic Report Protocol

This file defines an invented dataset for testing work-record and review flows. It is not experimental evidence.

Compare catalyst labels `Pd-X` and `Ni-Y` against substrate labels `A`, `B`, and `C`. Record yield and purity percentages for all six combinations.

Illustrative thresholds:

- Yield: at least 70% on each substrate.
- Purity: at least 98% on each substrate.

A catalyst meets the illustrative rule only when both thresholds hold for all three substrate labels. All values in the report are synthetic and support no chemistry or production conclusion.
