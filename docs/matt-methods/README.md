# Matt's methods, read from the source

Answers to questions about how this repository should be shaped, each read from [`mattpocock/skills`](https://github.com/mattpocock/skills) rather than from memory, and each written per `.agents/rules/rules-matt.md`. One file per skill of his that answered a question.

The vendored copy the first answers were read from, `.agents/matt-skills/`, was dropped on 2026-11-12 (commit `bb4b5be`); each file still names the path inside his repository that it was read from, which is what to open to check it.

| File | Answers |
|---|---|
| `domain-modeling.md` | Where a record's format lives, how a field table is written, and how ADRs and the glossary are recorded |
| `writing-for-agents.md` | What a skill holds, how one skill reaches another, and what a pointer is for |

Each file records the question, the passage or file that answered it, and what this repository does because of it.
